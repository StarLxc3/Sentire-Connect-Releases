# Sentire Connect releases

Official desktop installers for Windows, Linux, and macOS (Apple Silicon and Intel).

- Website and installation guide: https://starlxcdesktop.tail6c4334.ts.net/
- Downloads: https://github.com/StarLxc3/Sentire-Connect-Releases/releases/latest

This repository distributes application binaries and SHA-256 checksums. It does not contain application source code, service credentials, or user data.

Use the version-matched release.json and SHA256SUMS.txt to verify downloads. macOS packages use ad-hoc signing and are not Apple-notarized.
